# CoffeeFlow v1.0.1

Повний навчальний вебзастосунок для попередніх замовлень у кав’ярні: Flask, SQLite, HTML, CSS та JavaScript. Front-end працює з реальним REST API. Node.js потрібний лише для автоматизованих браузерних тестів.

## Стабільна версія

Версія v1.0.1 від 03.10.2026 оновлює документацію. Підготовка базової версії: 01.10.2026. Фінальні перевірки: **33 Python-тести та по 18 сценаріїв у Chrome й Edge**. Див. [опис релізу](RELEASE_NOTES.md), [чекліст](docs/FINAL_CHECKLIST.md) та [сценарій демонстрації](docs/DEMO.md). Історичні результати Практичної 6 наведено нижче окремо.

## Що реалізовано

- Меню, категорії, пошук і повідомлення про відсутність товарів.
- Кошик зі зміною кількості, видаленням і збереженням між відвідуваннями.
- Оформлення замовлення, перевірка полів, підтвердження та перегляд власних замовлень.
- Вхід адміністратора, зміна статусів замовлень, створення, редагування й видалення товарів та категорій.
- Адаптивний інтерфейс, завантаження, повторне читання після помилки, захист від повторного натискання кнопки відправлення.

## Запуск у Windows

Розпакуйте архів, відкрийте PowerShell у папці проєкту. Потрібен Python 3.11 або новіший. Виконайте команди по черзі:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m flask --app coffeeflow init-db
.\.venv\Scripts\python.exe -m flask --app coffeeflow seed-demo
.\.venv\Scripts\python.exe -m flask --app coffeeflow create-admin
.\.venv\Scripts\python.exe -m flask --app coffeeflow run --host 127.0.0.1 --port 5000
```

Якщо встановлено іншу версію Python, замініть `py -3.11` на відповідну команду `py -3.12` або `python`. Активація середовища не потрібна. Для встановлення залежностей потрібний інтернет.

Команда `create-admin` запитає ваші логін і пароль: логін 3–40 символів, пароль 12–128 символів. Постійного стандартного пароля в застосунку немає.

Відкрийте **http://127.0.0.1:5000**. Поки користуєтеся сайтом, залишайте термінал відкритим. Для зупинки натисніть Ctrl+C.

| Адреса | Призначення |
|---|---|
| `/` | Меню й кошик |
| `/checkout` | Оформлення замовлення |
| `/orders` | Власні замовлення |
| `/admin` | Панель адміністратора |
| `/api/v1/openapi.json` | Машиночитаний опис API |

Не відкривайте HTML-шаблони подвійним натисканням: їх формує Flask. Локальна база та секрет створюються в `instance` і не входять до архіву. `init-db` не видаляє наявні дані, а `seed-demo` призначений для порожнього каталогу. Попередню базу переносіть лише після зупинки обох серверів, зберігши резервну копію.

## Демонстрація застосунку

1. Додайте напій у кошик, змініть кількість і відкрийте оформлення.
2. Укажіть ім’я, телефон і час отримання, надішліть замовлення.
3. Збережіть показаний номер. Відкрийте `/admin`, увійдіть зі створеним обліковим записом.
4. Змініть статус замовлення. Поверніться до власних замовлень і натисніть оновлення.
5. Покажіть редагування меню та вузьку ширину вікна браузера.

## Перевірки

Python:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -v
```

Браузерні сценарії запускаються окремо на тимчасовій базі, порт 5016. Для них потрібен Node.js. У першому терміналі:

```powershell
.\.venv\Scripts\python.exe tests/serve_ui.py
```

У другому терміналі з тієї самої папки:

```powershell
npm install
npx playwright install chromium
npm run test:ui
```

Або використайте встановлений Chrome, пропустивши завантаження Chromium:

```powershell
$env:BROWSER_EXECUTABLE='C:\Program Files\Google\Chrome\Application\chrome.exe'
npm run test:ui
```

Тестовий сервер створює виключно тимчасовий обліковий запис `tester` / `Ui-test-only-2026!`. Не використовуйте його для реальних даних. Після зупинки тестового сервера тимчасова база видаляється.

23.09.2026 успішно виконано **33 перевірки Python та 18 браузерних сценаріїв**. Результати, межі перевірки й скриншоти містяться в `docs/TEST_RESULTS.md` та `docs/screenshots`.

## Структура

- `coffeeflow/templates` — сторінки та спільний шаблон.
- `coffeeflow/static/js` — API, кошик, компоненти й логіка сторінок.
- `coffeeflow/static/css` і `images` — стилі та власні SVG-ілюстрації.
- `coffeeflow/routes`, `services`, `schema.sql` — серверна частина.
- `tests` — серверні та браузерні перевірки.
- `docs/API.md`, `openapi.json` — контракт API; `docs/FRONTEND.md` — опис інтерфейсу.
- `Практична_робота_6_CoffeeFlow.docx` — звіт про реалізацію клієнтської частини.

## Межі MVP

Оплата відбувається в кав’ярні. Онлайн-оплату, доставку, автоматичні сповіщення й облік пропускної здатності закладу не реалізовано. Статус оновлюється кнопкою. Доступ до гостьового замовлення залежить від cookie поточного браузера; відновлення після втрати cookie не реалізовано.

У localStorage зберігаються лише ідентифікатори товарів, кількість і до 20 номерів замовлень, без телефону та імені. При повному блокуванні сховища кошик може не зберегтися після переходу на іншу сторінку. Сервер перевіряє ціни й права незалежно від клієнта.

Мережеву помилку при створенні замовлення не можна трактувати як гарантовану відсутність замовлення: сервер міг його прийняти. Клієнт не повторює таку операцію автоматично. Серверного ключа ідемпотентності немає.

Це локальний навчальний запуск. Публічне розгортання потребує окремого налаштування HTTPS і промислового сервера. Правила роботи з Git наведені в `docs/WORKFLOW.md`; порядок фіксації релізу — у `docs/ARCHIVING.md`.
