# Архівування стабільної версії

Назва релізу: CoffeeFlow v1.0.1. Основна гілка: main. Стабільна гілка: release-v1.0.1. Тег: v1.0.1, анотований. Опис: RELEASE_NOTES.md.

## Порядок фіксації

1. Перевірити робоче дерево та склад файлів. Не включати instance/, секрети, залежності й кеші.
2. Виконати фінальні тести та додати журнали. Оновити README, опис релізу й чекліст.
3. Зафіксувати підготовлені файли комітом у main.
4. Створити release-v1.0.1 із того самого коміту, а потім анотований тег:

```powershell
git branch release-v1.0.1
git tag -a v1.0.1 -m "CoffeeFlow v1.0.1 stable educational release"
git show --no-patch v1.0.1
```

5. Надіслати гілки й тег у власний репозиторій та перевірити віддалені посилання:

```powershell
git push -u origin main
git push origin release-v1.0.1
git push origin v1.0.1
git ls-remote --heads --tags origin
```

Репозиторій: https://github.com/Sawabob/coffeeflow. Команди нижче призначені для підготовки нової версії; наявний опублікований тег повторно не створюють.

## Відтворюваний архів

```powershell
git archive --format=zip --prefix=CoffeeFlow-v1.0.1/ --output=../CoffeeFlow-v1.0.1.zip v1.0.1
git bundle create ../CoffeeFlow-v1.0.1.bundle --all
Get-FileHash ../CoffeeFlow-v1.0.1.zip -Algorithm SHA256
```

ZIP містить файли вибраного коміту, без службової .git. Bundle окремо зберігає історію та посилання Git. Для перевірки копії виконайте git bundle verify і пробне клонування у нову папку.

## Повернення до версії та подальша робота

```powershell
git fetch origin --tags
git switch --detach v1.0.1
```

Цей режим придатний для перегляду та запуску. Для наступних змін створіть гілку, наприклад git switch -c feature/next-stage v1.0.1. Не пересувайте опублікований тег: наступний реліз позначайте новим номером.

Тег не є технічно незмінним: Git допускає його видалення або примусове пересування. Стабільність забезпечується командними правилами, резервними копіями та, за потреби, правилами захисту тегів на сервері. Архівування версії тегом не означає переведення всього GitHub-репозиторію в режим read-only Archive.
