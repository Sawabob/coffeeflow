# Результати перевірки Практичної роботи 6

Дата: 23.09.2026. Середовище: Windows, Python 3.12.14, Flask 3.1.2, Playwright 1.62.1, встановлений Google Chrome у headless-режимі. Локальний тестовий Flask-сервер використовував тимчасову SQLite і окрему тестову сесію.

## Python

Команда: python -m unittest discover -v. Результат: **33 тести, OK, 26,016 секунди**. З них 28 тестів API та 5 нових перевірок Front-end HTTP: HTML-сторінки, статичні файли, адміністративні права, відсутність приватних даних у шаблонах, JSON-помилка при недоступній базі.

Повний журнал: backend-tests-practical6.txt. OperationalError у ньому є очікуваним результатом навмисного тесту відсутньої бази, а не провалом запуску.

## Браузер

Команда: node tests/frontend.e2e.cjs. Результат: **18 сценаріїв passed**. Повний перелік: frontend-test-results.json. Перевірено реальне отримання каталогу, пошук, категорії, кошик і його збереження, валідацію полів на клієнті та сервері, створення одного замовлення, недоступність чужого гостьового замовлення, вхід, вихід, зміну статусу, CRUD категорій і товарів та конфлікт видалення категорії з товарами.

Три групи перевірок станів використовували підміни Playwright: затримка/503/повтор, мережевий збій/порожня відповідь, недоступний товар. Це контрольовані перевірки поведінки Front-end; вони не є тестом реального збою інфраструктури. Інші інтеграційні сценарії зверталися до локального API.

Адаптивність перевірена при ширині 390, 768 і 1440 px. Неконтрольованих помилок JavaScript у перевірених сценаріях не виявлено. Скриншоти лежать у screenshots; візуально перевірено меню на широкому та вузькому екранах, оформлення й адміністративні замовлення.

## Межі перевірки

Не проводилися тести Firefox/Safari, фізичних телефонів, повний аудит WCAG, навантажувальне тестування та публічне розгортання. Перевірка подвійного натискання не доводить загальну ідемпотентність: серверний ключ повторного запиту не реалізовано.
