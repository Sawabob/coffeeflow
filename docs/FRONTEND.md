# Інтерфейс CoffeeFlow

Окремого затвердженого макета не надано. Дизайн створено під час роботи, без заяв про дослідження користувачів або прототип у Figma.

## Компоненти й оформлення

Клієнтський потік: меню → кошик → оформлення → підтвердження → стан замовлення. Адміністративний: вхід → замовлення / товари / категорії → зміна даних → вихід.

Кремове тло #f8f5ef, темний текст #30251e, зелені акценти; Georgia для заголовків, Arial для тексту. Ілюстрації — локальні SVG. Grid і Flexbox з медіазапитами 1080 та 760 px перебудовують колонки. Видимий фокус, підписи полів, aria-live, Escape для діалогів, клавіатура для вкладок, reduced-motion. Повний аудит WCAG не проводився.

## Сторінки та API

| Сторінка | Операції |
|---|---|
| shop.html | GET /api/v1/products і /categories; пошук, категорії, кошик |
| checkout.html | GET /products; POST /orders |
| orders.html | GET /orders/{id} у поточній гостьовій сесії |
| admin.html | /auth/me, /auth/login, /auth/logout; CRUD /products і /categories; читання /orders та зміна статусів |

Точні маршрути, параметри й відповіді див. API.md та openapi.json. api.js централізує fetch, same-origin cookie, JSON, CSRF і тайм-аут 15 секунд. Повтор операції зміни можливий лише один раз після явного csrf_failed, коли сервер відхилив її до виконання. Автоматичного повторення після мережевої помилки немає.

state.js зберігає product_id/quantity і до 20 номерів замовлень. Ім’я та телефон у localStorage не зберігаються. При блокуванні сховища працює пам’ять поточної сторінки; між сторінками збереження не гарантоване. ui.js екранує текст для HTML, форматує суми й дати та формує спільні компоненти. Модулі сторінок підключають їх відповідно до сценарію.

## Стани

Завантаження відображається до завершення запиту. Порожній каталог, пошук і кошик мають пояснення. Помилки читання дозволяють повторити запит. Поля форми зберігаються після серверної помилки. При надсиланні кнопка блокується; після успіху кошик очищується й відкривається підтвердження. При втраті сесії адміністратора показується вхід. Недоступні позиції потрібно вилучити з кошика. Сервер заново перевіряє товари, ціни й права доступу.
