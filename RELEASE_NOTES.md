# CoffeeFlow v1.0.0

Дата підготовки: 01.10.2026. Перша стабільна навчальна версія для локальної демонстрації та подальшої роботи.

## Можливості

- Меню, категорії, клієнтський пошук і доступність товарів.
- Кошик зі зміною кількості, видаленням і збереженням у браузері.
- Замовлення без реєстрації, контактні дані, час самовивозу та перегляд стану.
- Панель працівника: вхід, керування товарами й категоріями, зміна статусів.
- REST API, SQLite, серверний розрахунок у копійках та атомарне створення замовлення.
- Захист адміністративних операцій, CSRF, хеші паролів, валідація й обмеження частоти окремих запитів.

## Зміни під час підготовки релізу

Підтверджено наявний функціонал фінальними перевірками. Додано актуальний чекліст, журнали перевірок, сценарій демонстрації та інструкцію архівування. Програмна логіка, технологічний стек і схема БД не змінювалися. Виправлення функціональних помилок не заявляються: у виконаних сценаріях їх не виявлено.

## Перевірка 01.10.2026

- Python unittest: 33 тести, OK, 24,263 с.
- Google Chrome: 18 сценаріїв, усі пройдено.
- Microsoft Edge: 18 сценаріїв, усі пройдено.
- Ширини екрана: 390, 768 та 1440 px. Фізичний телефон не використовувався.
- Журнали й нові знімки екрана: docs/release-v1.0.0/.

Це два браузери на Chromium, а не два різні браузерні рушії. Окремі негативні сценарії підміняють відповіді API для перевірки реакції інтерфейсу; основний користувацький цикл виконує справжні запити до Flask із тимчасовою SQLite.

## Відомі обмеження

Самовивіз та оплата при отриманні. Немає доставки, онлайн-оплати, реєстрації клієнтів, автоматичних сповіщень, відновлення гостьового доступу після втрати cookie, серверної ідемпотентності та контролю завантаження часових слотів. Статус оновлюється вручну. Публічне розгортання, навантажувальне тестування й повний аудит доступності не виконувалися.

Локальні дані instance/, секрети, Python/Node-залежності та кеші не входять до вихідного архіву. Схема й демонстраційні дані відтворюються командами README. Для виробничого запуску потрібні окремі налаштування сервера, HTTPS і резервного копіювання.
